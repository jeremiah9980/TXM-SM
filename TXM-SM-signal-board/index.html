How this site ships

3 steps

This repo is also the worked example for the first GitHub topic: publishing Pages through Actions instead of the branch setting.

01

Commit to main

Edit index.html and push. No build tooling, no dependencies — the site is one file plus a workflow.

02

Actions builds it

.github/workflows/pages.yml runs on every push to main, uploads the repo root as a Pages artifact, and deploys it.

03

Pages serves it

Set Settings → Pages → Source to GitHub Actions once. After that every push republishes in about a minute.
